# Compact Multilingual synthetic retrieval corpus v1

This versioned corpus is entirely fictional and safe to reuse for local retrieval experiments. It contains generic HR, security, IT operations, support, procurement, travel, API, and data-retention policies. It includes intentionally similar policies with different thresholds and periods, including archived-vs-current 2024/2025 travel rules; 132 answerable cases; and 24 insufficient-evidence cases.

The checked-in `documents.json`, `dataset.json`, and `manifest.json` are generated by:

```bash
DATABASE_URL=sqlite+aiosqlite:///:memory: python -m evaluation.corpora.compact_multilingual_v1.generator
```

The generator is deterministic. `fingerprint_sha256` hashes the version, ordered document records, and validated evaluation dataset using canonical UTF-8 JSON. Tests assert the committed corpus fingerprint and language/cross-language/no-answer distributions.

Every document belongs to the synthetic Knowledge Base ID `1`; all cases use fixed `top_k=3`. Answerable query languages are balanced at 66 English and 66 Turkish cases, including 22 Turkish-query → English-source and 22 English-query → Turkish-source cases. There are 12 no-answer cases in each query language. The manifest also records case-type counts and both cross-language directions. Do not add real company, customer, employee, credential, or production data to this public corpus.

The corpus is reusable for embedding, reranker, hybrid, and future retrieval experiments. Keep each model/revision/preprocessing combination in its own temporary vector collection; the equal 384-dimensional MiniLM and E5 vectors are not interchangeable.
