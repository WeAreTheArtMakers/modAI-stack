# Local reranker v1 — BLOCKED BY MODEL PROVISIONING

## Status

The evaluation-only reranker integration, ONNX backend configuration, and offline/error-path tests are implemented, but the real model experiment was **not run**. The selected model's official ARM64 qint8 artifact was confirmed at the exact revision below. A minimal allow-list download of tokenizer/config support files plus that one ONNX file reached 5/6 files in about three minutes, then stopped making progress: the ONNX `.incomplete` blob remained 0 bytes. The transfer was cancelled cleanly; the older partial PyTorch cache was preserved and not deleted. No offline model initialization or reranker inference succeeded. Candidate pools 6/8/10, quality, rank movement, and reranker latency are therefore **unmeasured**. **No production reranker recommendation can be made until the model is provisioned and evaluated.**
